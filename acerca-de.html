7Metros

Plataforma de estadísticas, análisis y rendimiento para handball argentino. Esta versión es una interfaz estática funcional, lista para GitHub Pages y preparada para integrarse más adelante con Python/Flask y SQLite.

1. Interfaz webDashboard, navegación y diseño responsive.
2. SeccionesClubes, jugadores, planteles, partidos y estadísticas.
3. BackendConexión con Flask, API y base SQLite.
4. Usuarios + IAPermisos, carga protegida y análisis inteligente.
